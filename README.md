# WarpGUI — Minecraft 1.21.8

Fabric 客户端模组，为 HAW（Home and Warp）提供图形化传送点界面。

> 当前分支：`mc-1.21.8`  
> 本分支**只包含** Minecraft 1.21.8 的完整工程源码（位于仓库根目录）。

## 构建

**要求：** Java 21+

```bash
# Windows
gradlew.bat build

# Linux/macOS
chmod +x gradlew && ./gradlew build
```

产物：`build/libs/warp-gui-2.0.1.jar`
